# 💻 Desktop Software

BugSplat provides best-in-class support for desktop software — from native Windows [C++](cplusplus/) and [.NET Framework](windows-dot-net-framework.md) applications to [.NET Standard](../cross-platform/dot-net-standard.md), [macOS](macos.md) 11.5+ (including ARM Macs), and [Linux](linux.md). It also covers cross-platform desktop frameworks and languages — [Electron](../cross-platform/electron.md), [Qt](../cross-platform/qt.md), [Java](../cross-platform/java.md), and [Python](../cross-platform/python.md) — plus the native [Crashpad](../cross-platform/crashpad/) and [Breakpad](../cross-platform/breakpad.md) crash handlers. Take a look at the guides below to configure crash reporting in your app.
